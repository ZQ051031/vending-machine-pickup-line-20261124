## The line

> Are you exact change? Because every time you walk by, my coin slot lights up and I can't make change for anyone else.

A vending machine, doing its best to be charming: it speaks in coin slots, exact change, and the one small light that comes on when the right person walks past. Charming, not creepy — it just can't make change for anyone else.

## How it works

`main.py` (Python standard library only) writes the line to `/output/entry.txt`, with no trailing newline. Run it twice and the output is byte-identical.

```
python3 main.py
```
