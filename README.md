A vending machine tries its luck on a passing human — one line, one minute.
It speaks in coin slots and exact change, and its little light only comes on
for the right person walking by.

## Entry

> Are you exact change? Because every time you walk by, my coin slot lights up and I can't make change for anyone else.

## How it works

`main.py` is standard library only. It writes the single pickup line to
`/output/entry.txt` (no trailing newline) and enforces the 120-character
cap before writing.

```sh
python3 main.py
```
